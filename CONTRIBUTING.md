# Contributing to Job-Hunting-skill

We welcome contributions from career coaches, recruiters, software engineers, and the open-source AI community!

---

## Areas We'd Love Help With
1. **New LaTeX Templates:**
   - Templates for Executive, Academic (Curriculum Vitae), or Creative roles.
   - Additional color accents or alternate typography styles (e.g. EB Garamond, Inter).
2. **Multilingual Support:**
   - Templates and prompt translations in German, Spanish, Arabic, Italian, Portuguese, or Japanese.
3. **Agent Adapters:**
   - Enhancing compatibility with emerging agentic harnesses (e.g. OpenHands, Aider, Devin, AutoGPT).
4. **Tool Improvements:**
   - Extending `tools/extract_profile.py` with OCR for scanned image PDFs.
   - Enhancing `tools/setup_latex.py` for more niche Linux distributions.

---

## Contribution Workflow
1. Fork the repository on GitHub (`https://github.com/Fahedmb/Job-Hunting-skill`).
2. Create a feature branch: `git checkout -b feature/amazing-feature`.
3. Commit your changes: `git commit -m "Add feature XYZ"`.
4. Push to your branch: `git push origin feature/amazing-feature`.
5. Open a Pull Request!
